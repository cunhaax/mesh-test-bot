Começa aqui

Três passos. Não precisas de saber nada sobre Docker: copias umas linhas, colas, e carregas em Enter.

Antes de começar

  • ⏰ O computador tem de estar ligado à hora do teste, com o Docker a correr. Um Raspberry Pi é o ideal, porque fica sempre ligado. Um portátil em suspensão perde o teste.
  • 📡 O teu rádio está configurado na app Meshtastic, com o canal de testes já adicionado. O bot não configura o rádio.
  • 📵 Fecha a app Meshtastic durante um teste. O rádio só fala com um programa de cada vez.

1. Instala o Docker

O Docker é uma aplicação gratuita que corre o bot por ti, para não teres de instalar mais nada.

  • Windows ou Mac: instala o Docker Desktop e abre-o. Se pedir para reiniciar ou instalar o WSL, aceita. Espera até indicar que o motor está a correr, e deixa-o aberto. Nas definições, ativa o arranque ao iniciar sessão.
  • Raspberry Pi ou Linux: cola estas linhas no terminal, e depois termina a sessão e volta a entrar: 
    curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

2. Escolhe a tua situação

📁 Primeiro, escolhe onde o bot vai ficar. Os comandos abaixo criam uma pasta mesh-test-bot dentro da pasta onde o terminal está. Quando abres um terminal novo, essa é a tua pasta pessoal, e é um bom sítio. Para usar outra pasta, vai primeiro até lá, por exemplo com cd Documents. Evita as Transferências e pastas sincronizadas com a nuvem.

Não apagues nem movas esta pasta. Guarda as tuas definições e os teus relatórios, e vais precisar dela sempre que quiseres ver, alterar ou parar o bot.

Um rádio sem WiFi é normalmente um RAK4631 ou um T-Echo. Abre a opção que te serve.

📶 Rádio com WiFi · Mac, Raspberry Pi ou Linux
  1. Liga o rádio ao teu WiFi na app Meshtastic, e aponta o endereço IP (algo como 192.168.1.50). Costuma aparecer no ecrã do rádio, ou na lista de dispositivos do teu router.
  2. Aponta o nome e o número do canal de testes: o primeiro canal na app é o 0, o seguinte é o 1, e assim por diante.
  3. Abre o Terminal e cola esta linha: 
    curl -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/install.sh | sh
  4. Responde às perguntas. Carrega em Enter para aceitar a sugestão entre [parênteses retos]; só precisas de escrever o IP do rádio, o canal e a tua cidade. As perguntas aparecem em inglês.
  5. Cola as linhas que aparecem no fim, debaixo de "To start it". Antes delas, corre cd mesh-test-bot.
📶 Rádio com WiFi · Windows
  1. Liga o rádio ao teu WiFi na app Meshtastic, e aponta o endereço IP (algo como 192.168.1.50). Costuma aparecer no ecrã do rádio, ou na lista de dispositivos do teu router.
  2. Aponta o nome e o número do canal de testes: o primeiro canal na app é o 0, o seguinte é o 1, e assim por diante.
  3. Abre o PowerShell a partir do menu Iniciar e cola estas linhas. A última abre um ficheiro no Bloco de Notas: 
    mkdir mesh-test-bot
cd mesh-test-bot
mkdir data
curl.exe -fsSLO https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/docker-compose.yml
curl.exe -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/env.example -o .env
notepad .env
  4. No Bloco de Notas, muda o texto depois do = nestas quatro linhas: MTBOT_HOST (o IP), MTBOT_CHANNEL (o número), MTBOT_CHANNEL_NAME e MTBOT_PLACE (a tua cidade). Guarda e fecha.
  5. De volta ao PowerShell, cola: 
    docker compose up -d
🔵 Rádio só com Bluetooth · Raspberry Pi ou Linux

Isto arranca três coisas em conjunto: uma ponte Bluetooth, o MeshMonitor e o bot. Mantém o rádio a cerca de 10 m do computador, no máximo. A app no telemóvel não pode usar Bluetooth enquanto a ponte estiver ligada.

  1. Emparelha o rádio, uma vez. Cola estas linhas uma a uma: 
    bluetoothctl
agent on
default-agent
scan on
    Espera por Meshtastic_XXXX e aponta o endereço; depois, com o teu endereço: 
    pair AA:BB:CC:DD:EE:FF
trust AA:BB:CC:DD:EE:FF
exit
    O PIN está no ecrã do rádio. Um rádio sem ecrã usa 123456, a não ser que o tenhas mudado.
  2. Descarrega os ficheiros e abre as definições: 
    mkdir mesh-test-bot && cd mesh-test-bot && mkdir data
curl -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/with-ble.yml -o docker-compose.yml
curl -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/ble.env.example -o .env
nano .env
  3. Muda os cinco valores: o endereço do rádio, o endereço onde vais abrir o MeshMonitor, o número do canal, o nome do canal e a tua cidade. Para guardar e sair do nano: Ctrl+O, Enter, Ctrl+X.
  4. Arranca tudo: 
    docker compose up -d
  5. Num navegador, abre o endereço do MeshMonitor que escreveste, na porta 8080. Entra com admin / changeme e muda a palavra-passe.
  6. Vai a Dashboard → Sources, edita a fonte do rádio e ativa Enable Virtual Node, com a porta 4404 e Admin commands desligado. O bot liga-se sozinho em poucos minutos.

Ninguém testou ainda esta configuração com o bot num rádio real. Se experimentares, conta-nos como correu. Mais detalhes (em inglês).

🔵 Rádio só com Bluetooth · Windows

O Docker Desktop não chega ao Bluetooth, por isso uma pequena aplicação do Windows trata dessa parte.

  1. Emparelha o rádio em Definições → Bluetooth e dispositivos → Adicionar dispositivo.
  2. Descarrega o meshtastic-ble-bridge.exe e corre-o, seguindo a página BLE Bridge do MeshMonitor (em inglês). Indica o endereço Bluetooth do rádio e deixa a porta em 4403.
  3. Abre o PowerShell a partir do menu Iniciar e cola estas linhas. A última abre um ficheiro no Bloco de Notas: 
    mkdir mesh-test-bot
cd mesh-test-bot
mkdir data
curl.exe -fsSLO https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/docker-compose.yml
curl.exe -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/env.example -o .env
notepad .env
  4. No Bloco de Notas, muda a linha MTBOT_HOST para MTBOT_HOST=host.docker.internal. Depois muda o texto depois do = em MTBOT_CHANNEL (o número), MTBOT_CHANNEL_NAME e MTBOT_PLACE (a tua cidade). Guarda e fecha.
  5. De volta ao PowerShell, cola: 
    docker compose up -d

Ninguém testou ainda esta configuração com o bot. Se experimentares, conta-nos como correu.

🔵 Rádio só com Bluetooth · Mac

O Bluetooth não funciona aqui: o Docker num Mac não lhe chega, e não há aplicação de ponte para Mac. Usa um Raspberry Pi se tiveres um, ou liga o rádio por cabo USB com estes passos (em inglês).

3. Confirma que funciona

A partir da pasta mesh-test-bot, cola a linha abaixo. Se abriste um terminal novo, volta primeiro à pasta com cd mesh-test-bot (a partir do sítio onde a criaste). Todos os comandos docker compose desta página têm de correr nessa pasta.

docker compose logs -f --no-log-prefix bot

Em cerca de um minuto deves ver Startup check OK. A primeira linha diz quando é a próxima sessão. Carrega em Ctrl+C para deixar de ver: o bot continua a correr.

Depois de cada sessão, o relatório fica na pasta data, em report.txt.

Se algo correr mal

  • Um erro fala no Docker daemon, ou "docker" não é reconhecido: abre o Docker Desktop e espera até estar a correr, ou reinicia o computador.
  • Startup check FAILED: confirma o endereço IP, vê se o rádio está ligado e fecha a app Meshtastic. O bot continua a tentar sozinho. Com MeshMonitor, confirma que o Virtual Node está ativo.
  • Diz que o nome do canal não corresponde: é uma verificação de segurança. Corrige o número ou o nome no ficheiro .env, e cola docker compose up -d.
  • Queres mudar uma definição: edita o .env, e cola docker compose up -d.
  • Queres parar o bot: cola docker compose down.
  • Continuas com problemas? Abre um issue e cola o que a verificação do passo 3 mostra.
