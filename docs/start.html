EN PT

Start here

Three steps. You don't need to know anything about Docker: you copy a few lines, paste them, and press Enter.

Before you start

  • ⏰ The computer must be on at test time, with Docker running. A Raspberry Pi is ideal, because it stays on. A laptop that's asleep misses the test.
  • 📡 Your radio is set up in the Meshtastic app, with the test channel already added. The bot doesn't configure the radio.
  • 📵 Close the Meshtastic app during a test. The radio only talks to one program at a time.

1. Install Docker

Docker is a free app that runs the bot for you, so you don't have to install anything else.

  • Windows or Mac: install Docker Desktop and open it. If it asks to restart or to install WSL, say yes. Wait until it says the engine is running, and leave it open. In its settings, turn on starting when you sign in.
  • Raspberry Pi or Linux: paste these lines in the terminal, then log out and back in: 
    curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

2. Pick your setup

📁 First, choose where the bot will live. The commands below create a mesh-test-bot folder inside the folder your terminal is in. That's your personal folder when you open a new terminal, which is a fine place for it. To use another folder, go there first, for example with cd Documents. Avoid Downloads and folders synced to the cloud.

Don't delete or move this folder. It holds your settings and your reports, and you'll need it whenever you check, change or stop the bot.

A radio without WiFi is usually a RAK4631 or a T-Echo. Open the one that matches you.

📶 Radio with WiFi · Mac, Raspberry Pi or Linux
  1. Connect the radio to your WiFi in the Meshtastic app, and note its IP address (like 192.168.1.50). It's usually on the radio's screen, or in your router's list of devices.
  2. Note the test channel's name and number: the first channel in the app is 0, the next is 1, and so on.
  3. Open the Terminal and paste this line: 
    curl -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/install.sh | sh
  4. Answer the questions. Press Enter to accept the suggestion in [brackets]; you only need to type the radio's IP, the channel and your city.
  5. Paste the lines it shows at the end, under "To start it". Before them, run cd mesh-test-bot.
📶 Radio with WiFi · Windows
  1. Connect the radio to your WiFi in the Meshtastic app, and note its IP address (like 192.168.1.50). It's usually on the radio's screen, or in your router's list of devices.
  2. Note the test channel's name and number: the first channel in the app is 0, the next is 1, and so on.
  3. Open PowerShell from the Start menu and paste these lines. The last one opens a file in Notepad: 
    mkdir mesh-test-bot
cd mesh-test-bot
mkdir data
curl.exe -fsSLO https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/docker-compose.yml
curl.exe -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/env.example -o .env
notepad .env
  4. In Notepad, change the text after = on these four lines: MTBOT_HOST (the IP), MTBOT_CHANNEL (the number), MTBOT_CHANNEL_NAME and MTBOT_PLACE (your city). Save and close.
  5. Back in PowerShell, paste: 
    docker compose up -d
🔵 Bluetooth-only radio · Raspberry Pi or Linux

This starts three things together: a Bluetooth bridge, MeshMonitor and the bot. Keep the radio within about 10 m of the computer. The phone app can't use Bluetooth while the bridge is connected.

  1. Pair the radio, once. Paste these lines one at a time: 
    bluetoothctl
agent on
default-agent
scan on
    Wait for Meshtastic_XXXX and note its address, then, with your own address: 
    pair AA:BB:CC:DD:EE:FF
trust AA:BB:CC:DD:EE:FF
exit
    The PIN is on the radio's screen. A radio with no screen uses 123456 unless you changed it.
  2. Download the files and open the settings: 
    mkdir mesh-test-bot && cd mesh-test-bot && mkdir data
curl -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/with-ble.yml -o docker-compose.yml
curl -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/ble.env.example -o .env
nano .env
  3. Change the five values: the radio's address, the address you'll open MeshMonitor at, the channel number, the channel's name and your city. To save and leave nano: Ctrl+O, Enter, Ctrl+X.
  4. Start everything: 
    docker compose up -d
  5. In a browser, open the MeshMonitor address you typed, on port 8080. Log in with admin / changeme and change the password.
  6. Go to Dashboard → Sources, edit the radio's source and turn on Enable Virtual Node, with port 4404 and Admin commands off. The bot connects by itself within a few minutes.

Nobody has run this setup with the bot on a real radio yet. If you try it, please tell us how it went. More details.

🔵 Bluetooth-only radio · Windows

Docker Desktop can't reach Bluetooth, so a small Windows app does that part.

  1. Pair the radio in Settings → Bluetooth & devices → Add device.
  2. Download meshtastic-ble-bridge.exe and run it, following MeshMonitor's BLE Bridge page. Give it the radio's Bluetooth address and leave the port at 4403.
  3. Open PowerShell from the Start menu and paste these lines. The last one opens a file in Notepad: 
    mkdir mesh-test-bot
cd mesh-test-bot
mkdir data
curl.exe -fsSLO https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/docker-compose.yml
curl.exe -fsSL https://raw.githubusercontent.com/cunhaax/mesh-test-bot/master/install/env.example -o .env
notepad .env
  4. In Notepad, change the MTBOT_HOST line to MTBOT_HOST=host.docker.internal. Then change the text after = on MTBOT_CHANNEL (the number), MTBOT_CHANNEL_NAME and MTBOT_PLACE (your city). Save and close.
  5. Back in PowerShell, paste: 
    docker compose up -d

Nobody has run this setup with the bot yet. If you try it, please tell us how it went.

🔵 Bluetooth-only radio · Mac

Bluetooth doesn't work here: Docker on a Mac can't reach it, and there's no Mac bridge app. Use a Raspberry Pi if you have one, or connect the radio by USB cable with these steps.

3. Check it works

From the mesh-test-bot folder, paste the line below. If you opened a new terminal, go back to the folder first with cd mesh-test-bot (from wherever you created it). Every docker compose command on this page must run from that folder.

docker compose logs -f --no-log-prefix bot

Within about a minute you should see Startup check OK. The first line says when the next session is. Press Ctrl+C to stop watching: the bot keeps running.

After each session, your report is in the data folder, in report.txt.

If something goes wrong

  • An error mentions the Docker daemon, or "docker" isn't recognised: open Docker Desktop and wait until it's running, or restart the computer.
  • Startup check FAILED: check the IP address, make sure the radio is on, and close the Meshtastic app. The bot keeps retrying by itself. With MeshMonitor, make sure the Virtual Node is on.
  • It says the channel's name doesn't match: this is a safety check. Fix the number or the name in the .env file, then paste docker compose up -d.
  • You want to change a setting: edit .env, then paste docker compose up -d.
  • You want to stop the bot: paste docker compose down.
  • Still stuck? Open an issue and paste what the check in step 3 shows.
